# 🎮 SM Gaming Box

SM Gaming Box is a mini gaming website developed as a second-year university project. It brings together simple browser-based games in one place, providing users with an enjoyable and interactive gaming experience.

## ✨ Features
- Multiple mini-games in one website
- Simple and user-friendly interface
- Browser-based gameplay
- Interactive game elements

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.2.3

## 🚀 How to Run
1. Download or clone this repository.
2. Extract the project files if downloaded as a ZIP file.
3. Open home.html in a web browser.
4. Choose a game and start playing!

## 🎯 Project Purpose
This project was created to practice front-end web development skills, including webpage structure, styling, and JavaScript interactivity.
